# Video placeholders

Drop MP4 files here — the site references them automatically:

- gym-showcase.mp4              → homepage main video
- services-showcase.mp4         → /services hero video
- service-<slug>.mp4            → per-service page video
  (gym, power-yoga-pilates, zumba, kickboxing, diet-nutrition, boot-camp, lower-body-weight-training)
- trainers-showcase.mp4         → /trainers video
- location-<slug>.mp4           → per-location page video
  (punjabi-bagh, rajouri-garden, paschim-vihar, janakpuri, kirti-nagar, prashant-vihar, dwarka)
- transformations-showcase.mp4  → homepage transformations video

Until an MP4 is present, each VideoBlock shows a poster image with a "Video placeholder" chip.
